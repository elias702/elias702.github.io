## Architecture & Deployment

This portfolio is deliberately engineered as a lightweight, zero-dependency static site designed for instant real-world performance and 100% native GitHub Pages compatibility:

- **Markup & Layout:** Clean semantic HTML5.
- **CSS Architecture:** Self-contained modern CSS design tokens with dark-first theme, near-black obsidian background, and subtle lime/emerald accents. No client-side runtime compilation overhead.
- **JavaScript:** Minimal vanilla JavaScript for accessible keyboard navigation, mobile drawer toggling, and one-click clipboard copying.
- **Metadata:** Rich Open Graph tags, Twitter Card metadata, and Schema.org `Person` JSON-LD.

### Run Locally

Open `index.html` directly in any web browser, or run a local static server:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

### Deploy to GitHub Pages

Push `index.html` and `README.md` to the repository's default branch. GitHub Pages serves the root directory out of the box with zero CI or build dependencies.
